# 4-bit-ALU-Verilog
4-bit ALU designed and verified using Verilog HDL and Xilinx Vivado, supporting 8 arithmetic and logical operations with functional simulation.
## Project Overview

This project presents the RTL design and functional verification of a
4-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU supports
eight arithmetic and logical operations selected through a 3-bit control
signal.

The design was developed using RTL modeling and verified using a
dedicated Verilog testbench in Xilinx Vivado. Functional correctness
was validated through simulation and waveform analysis.

## Supported Operations

- Addition
- Subtraction
- Bitwise AND
- Bitwise XOR
- Bitwise OR
- Bitwise NOT
- Increment
- Decrement

## Design and Verification

The project follows a basic RTL design and verification flow:

RTL Design → Testbench Development → Functional Simulation → Waveform Analysis
